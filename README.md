# Юридическая практика Евгении Бычихиной

Многостраничный продающий сайт юридических услуг на Next.js 16 / React 19.

## Что включено

- главная страница;
- пять самостоятельных страниц услуг;
- страницы «Обо мне», «Стоимость», «Контакты»;
- политика конфиденциальности и согласие на обработку данных;
- адаптивное меню и верстка для Android/iPhone;
- модальная и встроенные формы заявок;
- доставка заявок в Telegram, email, SMS и универсальный webhook;
- ссылка на онлайн-оплату;
- Schema.org `LegalService`, `Service`, `BreadcrumbList`, `FAQPage`;
- уникальные title/description, sitemap.xml, robots.txt и llms.txt;
- доступность с клавиатуры и поддержка `prefers-reduced-motion`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

После запуска откройте адрес, который будет указан в терминале. Обычно это
`http://localhost:3000` или `http://localhost:5173`.

Проверка production-сборки для обычного Next.js-хостинга:

```bash
npm run next:build
```

Сборка для ChatGPT Sites выполняется командой:

```bash
npm run build
```

## Настройка контактов

Основные публичные контакты находятся в `app/lib/content.ts`.

Перед запуском замените:

- `NEXT_PUBLIC_SITE_URL` — постоянный домен без завершающего `/`;
- `NEXT_PUBLIC_TELEGRAM_URL` — ссылка на Telegram-профиль;
- телефон и email в `contacts`, если они изменились.

## Доставка заявок

Скопируйте `.env.example` в `.env.local` и заполните один или несколько каналов.
Форма считается доставленной, если успешно сработал хотя бы один канал.

### Telegram

1. Создайте бота через `@BotFather`.
2. Напишите боту сообщение.
3. Получите ID чата через Telegram Bot API.
4. Укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

### Email

Создайте ключ в Resend и подтвердите домен отправителя. Заполните:

- `RESEND_API_KEY`;
- `LEAD_EMAIL_TO`;
- `LEAD_EMAIL_FROM`.

### SMS

Создайте ключ сервиса SMS.ru и заполните:

- `SMSRU_API_ID`;
- `LEAD_SMS_TO`.

### CRM, Make, n8n или Albato

Укажите `LEAD_WEBHOOK_URL`. При необходимости добавьте `LEAD_WEBHOOK_TOKEN`.
На webhook отправляется JSON с полями `name`, `contact`, `message`, `service`,
`source`.

Секретные ключи нельзя добавлять в Git. На хостинге их нужно задавать в разделе
Environment Variables / Secrets.

## Онлайн-оплата

Укажите в `NEXT_PUBLIC_PAYMENT_URL` ссылку платежного провайдера или созданную
платежную страницу. К ней автоматически добавляется параметр `service`.

До подключения ссылки кнопка «Заказать онлайн» открывает форму заявки и не
имитирует оплату.

## Бесплатное тестовое размещение

### 1. ChatGPT Sites

Проект уже совместим с Sites. Добавьте переменные окружения в настройках сайта,
сохраните новую версию и выполните production deployment.

### 2. Cloudflare Workers Free

Cloudflare поддерживает Next.js App Router и Route Handlers через OpenNext.

1. Создайте аккаунт Cloudflare.
2. Подключите Git-репозиторий или установите Wrangler.
3. Для существующего Next.js-проекта следуйте официальному сценарию:
   `npx wrangler deploy`.
4. Добавьте переменные и секреты в настройках Worker.

Документация:
https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/

### 3. Vercel Hobby или Netlify Free

Исходный код совместим с обычным Next.js:

1. Загрузите проект в GitHub/GitLab.
2. Подключите репозиторий к Vercel или Netlify.
3. Установите build command `npm run next:build`.
4. Добавьте переменные окружения.
5. Выполните deployment.

Vercel: https://vercel.com/docs/frameworks/full-stack/nextjs

Netlify: https://docs.netlify.com/build/frameworks/framework-setup-guides/nextjs/overview/

Бесплатные тарифы имеют лимиты. Перед публичным запуском проверьте актуальные
условия выбранной площадки и сервисов уведомлений.

## SEO и видимость в AI-ответах

После подключения постоянного домена:

1. Укажите домен в `NEXT_PUBLIC_SITE_URL`.
2. Добавьте сайт в Google Search Console и Яндекс Вебмастер.
3. Отправьте `/sitemap.xml`.
4. Проверьте Schema.org-разметку в Google Rich Results Test.
5. Создайте и заполните карточки организации в релевантных каталогах.
6. Регулярно публикуйте авторские разборы реальных правовых ситуаций без
   раскрытия персональных данных.
7. Поддерживайте сведения об опыте, услугах, ценах и контактах актуальными.

Google указывает, что для AI-функций поиска действуют базовые принципы SEO:
доступность для сканирования, полезный оригинальный контент, ясная структура и
корректные данные. Отдельная разметка не гарантирует верхние позиции или
попадание в ответы нейросетей.

Официальные материалы:

- https://developers.google.com/search/docs/fundamentals/ai-optimization-guide
- https://developers.google.com/search/docs/appearance/structured-data/organization
- https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a

## Перед публичным запуском

- замените тестовую ссылку Telegram;
- подключите минимум один канал доставки заявок;
- подключите платежную ссылку либо скройте обещание онлайн-оплаты;
- подтвердите окончательные цены;
- добавьте реквизиты исполнителя и порядок оплаты/возврата;
- проверьте политику конфиденциальности с учетом реальных сервисов и места
  хранения данных;
- проверьте необходимость уведомления Роскомнадзора и локализации персональных
  данных;
- не публикуйте сведения о клиентах и результатах дел без законного основания.

Информация на страницах сайта не является индивидуальной юридической
консультацией и не содержит гарантии результата по делу.
